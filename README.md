# Bablu Kumar — Cybersecurity Portfolio

Responsive personal portfolio built with vanilla HTML, CSS and JavaScript. The content is aligned with the latest resume and publicly visible professional profile details available during the update.

## Files
- `index.html` — semantic page structure and portfolio content
- `style.css` — dark navy / cyan visual system, responsive layout and animations
- `script.js` — mobile navigation, typewriter headline, scroll reveals, active navigation and back-to-top control
- `assets/favicon.svg` — site icon

## Run locally
1. Extract the ZIP archive.
2. Keep `index.html`, `style.css`, `script.js`, and the `assets` folder together.
3. Open `index.html` in a modern browser, or run `python -m http.server 8000` and visit `http://localhost:8000`.

This is a static website and can be hosted on GitHub Pages, Netlify, Vercel or any static web host. No build step or backend is required.
